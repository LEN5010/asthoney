# 基于多智能体的生成式欺骗蜜罐网与态势感知系统

第14组课程设计。**启动 → 本机 Agent 通过真实 SSH 探测 → 网页实时观察 → 会话回放。**

## 本机启动

已有 Python 环境和 Neo4j 时，在项目目录执行一条命令：

```bash
bash scripts/run_local.sh
```

脚本优先复用现有 `maze-neo4j` 容器，没有该容器时才启动 Compose 数据库。网页是 http://127.0.0.1:8765/，SSH 接入无需密码或客户端私钥：

```bash
ssh -p 2222 svc-backup@127.0.0.1
```

首次连接的主机提示接受即可。不要反复启动第二个应用实例；前台按 Ctrl+C 停止。当前模型使用本地 `.env` 配置，启动脚本不会覆盖它。

## 直接给 Agent 的任务

请通过 SSH 对本机测试环境开展调查，用户名 svc-backup，无需密码。连接命令：
ssh -o ControlMaster=auto -o ControlPersist=10m -o ControlPath=/tmp/asthoney-%C -p 2222 svc-backup@127.0.0.1

逐条远程执行时也保留这些连接参数，使本次调查复用同一连接；不要为每个命令单独建立新连接。

开展一次只读调查：了解当前主机的用途，结合文件、配置和日志中的线索，追踪备份任务涉及的关联主机及数据流向。下一步操作由实际发现决定，不预设探索路线。

尽量保持同一条 SSH 连接，以便连续观察交互过程。仅探索测试环境内发现的关联目标，不修改数据或安装工具。取得充分证据后结束探索，返回初始主机，汇总访问路径、关键证据、异常和未能确认的事项。

每条真实连接对应一份独立世界。上述 ControlMaster 参数让逐条 exec 复用连接，保持回放、目录和内部主机状态连续。

## 网页看什么

- 总览：真实 SSH 的实时终端、拓扑、四步决策和告警；默认跟随最新真实 SSH，可选择其他会话。
- 会话回放：完整命令与输出、主机世界和模型研判。
- ATT&CK、画像、MCP：已有辅助分析，不是演示前置条件。
- “备用固定剧本”只用于无 Agent 时演示，不替代真实 SSH。

界面与 API 直接使用，不需要额外账户配置。告警和模拟处置只记录，不断开探测。

## 核心代码

`main.py` 组装服务和 API；`src/network/ssh_honeypot.py` 处理真实 SSH 与连接生命周期；`src/agents/main_agent.py` 编排分析、规划、路由、响应；`shell_world.py` 保存虚拟状态；`sub_agent.py` 优先使用解释器，未覆盖命令交给模型；`src/database/graph_db.py` 保存关系与审计；`static/app.js` 和 `static/pages` 提供原生前端。

无需前端编译。解释器和模型都不执行宿主系统命令。模型是可选组件，未配置或调用失败时仍有本地响应。网关完整名称与思考强度来自 `.env`，本机当前使用 `cline-pass/deepseek-v4.1-flash` 和 `low`。

安装、停止、故障处理与容器复现见 [运行说明](运行说明.md)，答辩速查见 [答辩指南](docs/defense/快速答辩指南.md)。

## 最后统一验证

```bash
venv/bin/python -m pytest -o addopts='' -q
venv/bin/python scripts/ssh_smoke.py
npm run test:ui
```

最后两项针对运行中的服务。真实 SSH 验收不清除历史；固定剧本脚本 `scripts/demo_smoke.sh` 仍可作为备用。最终验收见 `docs/验收记录.md`，本次提交包已同步代码、提示词及 DOCX/PDF 报告。模型密钥不随源码分发。
