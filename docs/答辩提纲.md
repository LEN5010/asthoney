# 第14组答辩提纲

主演示：启动应用 → 本机 Agent 真实 SSH 探测 → 总览实时终端与路径 → 会话回放。

1. 在项目目录运行 `bash scripts/run_local.sh`，打开 http://127.0.0.1:8765/。
2. Agent 使用 `ssh -p 2222 svc-backup@127.0.0.1`，无需密码或登录私钥，保持同一连接。
3. 让 Agent 自主选择探测命令，不要求照固定剧本执行。观察真实输入、响应、当前主机与决策。
4. 选一条命令解释读取线索、内部 SSH 切换、JIT 合成和返回原主机后状态延续。
5. 打开会话回放与主机世界，按需点击“开始研判”。告警只记录，不断开连接。

多智能体是职责分工，不是多个模型辩论；内部主机是虚拟世界，不是新建真实虚拟机。固定剧本仅备用，ATT&CK、画像与 MCP 可在追问时补充。
