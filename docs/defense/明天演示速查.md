# 明天演示速查

## 开始前

打开 Docker Desktop。在一个终端启动（已有实例在运行就不重复启动）：

```bash
cd "你的解压目录/代码"
bash scripts/run_local.sh
```

打开 <http://127.0.0.1:8765/>；需要从头演示时点击右上角“重置演示”并确认。随后保留“SSH 实时终端”和拓扑区域。新开 Agent 对话，把同目录 `Agent探索提示词.txt` 全文粘贴给它即可；不需要把项目源码或以前的聊天交给 Agent。

## 演示时

- 让 Agent 自己从文件选线索，不在旁边再开 SSH 干扰“最新会话”选择。
- 网页跟随当前 SSH 会话，观察命令、路径和决策；发现归档证据、返回入口后结束探索。
- Agent 已完成但画面还要讲：复用连接会闲置保留约 10 分钟；历史会话不会随连接结束消失。
- 讲模型时可单独点击“开始研判”；基础命令由虚拟解释器处理，不能声称本次每条命令都调用了模型。

## 卡住就这样处理

不要现场重写代码、反复重连或换提示词。若 SSH 命令超过 12 秒没有响应，让 Agent 报告卡点，切换已保存的彩排会话回放；明确说明这是预先记录的真实 SSH 交互。Agent 思考时间不等于 SSH 命令响应时间。

当前提示词只说明调查目标和只读范围，不指定命令、路径或主机数量。已有彩排采用更具体的操作约束，不能当作当前简洁提示词的独立测试结果。
