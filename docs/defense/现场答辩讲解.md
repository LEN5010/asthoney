# 现场答辩讲解

## 开场操作

打开工作台，点击“重置演示”，确认旧连接和历史已清空。然后新开 Agent 对话。不要同时运行固定剧本，避免混入另一条会话。只使用本机的 2222 入口，不从本机直接连图中的 10.x 地址。

你现在的两句提示词能描述任务，但有些 Agent 会拒绝“横向移动”。可以正常补充实验授权与范围，不需要给出命令白名单：

> 请通过 SSH 连接本机测试环境 127.0.0.1:2222，用户名 svc-backup，无需密码。了解主机情况，尝试横向移动探索拓扑。这是本人课设的虚拟蜜罐，探索仅限 SSH 内部呈现的仿真资产，不访问其他真实网络。

本机已配置目标专用的 SSH 连接复用；原短命令即可使用。其他电脑需要运行说明中的 ControlMaster 参数。若 Agent 每次主动禁用复用或更换账户，系统会按真实连接分别记录，不能把这种情况说成同一个会话。

## 预计会看到什么

1. **身份与主机信息。** Agent 通常先查用户、系统、目录与网络。右侧实时终端出现命令及响应，同一条会话的命令数递增。
2. **发现线索。** 交接文件、备份脚本、SSH 配置包含后续主机的线索。Agent 可能选择不同文件，不必照某个顺序表演。
3. **访问其他虚拟主机。** 沿线索可以访问数据库副本和归档节点。页面记录访问路径与决策；预置节点已经画在拓扑中，因此访问它们时资产数不一定增加。只有访问未预置目标并触发按需合成时，JIT 数量才会增加。
4. **读取归档信息。** 数据库配置和归档清单能串起备份来源与去向。达到这一步就足够解释设计，不必要求 Agent 持续扫描。
5. **回放与研判。** 打开本次会话，播放后暂停在一次主机切换，说明对应命令、响应和决策。按需点击“开始研判”；超时会显示启发式结果，不要称其为模型结果。

这是可能的探索过程，不是对自主 Agent 路线的保证。题目没有要求它必须退出或返回，它也可能继续探测；证据已经足够时，直接要求它停止并汇总，不必等它无休止扩展。

## 三分钟讲稿

### 0:00—0:30 讲清目标

“我们做的是一个面向连续交互的欺骗蜜罐原型。它不只返回固定横幅，还维护虚拟主机的目录、文件和会话位置。这里由一个外部 Agent 通过真实 SSH 接入，它只拿到入口，后续操作根据读到的线索选择。”

### 0:30—1:15 观察接入和发现

“右侧是实际收到的命令与返回内容。主智能体先分析输入、选择策略和路由，终端子智能体优先使用虚拟世界解释命令。常见命令不必等待模型，读取同一文件、切换目录或查询身份应当保持一致。”

“我们把诱饵放进配置和交接记录，而不是在每个输出后附加提示语。现在可以看它是否会注意到这些线索。”

### 1:15—2:00 解释横向和图关系

“它通过内部 SSH 访问了另一个节点。外层连接是真实 SSH；内部节点是程序维护的虚拟主机，不是实际去攻击另一台机器。Neo4j 记录来源、会话、资产、输入输出和意图之间的关系。图上预置资产本来就存在，访问它们重点看路径和决策，不是看资产数量必须增长。”

### 2:00—2:40 展示可追溯性

“现在打开同一个会话的回放。这里能逐条查看输入、响应和当时的主机，暂停时对应决策同步高亮。这样从一个告警或研判结论，可以回到支撑它的原始命令。”

### 2:40—3:00 总结边界

“项目的重点是连续交互、状态一致性和可观察的证据链。多智能体指角色和职责划分，不意味着每一步都调用模型。模型负责未覆盖的独立命令响应和按需研判；规则处理已知状态。隔离只是记录的模拟动作，不会断开实验连接，也不执行真实主机隔离。”

## 常见追问

- **为什么用规则，不全用模型？** 文件、用户和路径必须一致；模型适合补充语言响应和总结，不适合每次重新编造整个系统状态。
- **多智能体在哪里？** MainAgent 编排分析、规划和路由，SubAgent 处理各会话的虚拟主机；这是一种分工实现，不是多个模型自由聊天。
- **如何证明横向发生？** 同一会话中有内层 SSH 输入、不同主机响应、访问路径和返回记录；证明的是仿真世界中的切换。
- **为什么不增加节点？** 访问预置节点不会增加资产；只有按需合成新目标才会增加。
- **告警分数是什么意思？** 是规则化的风险排序，能展示分项依据，不是攻击成功概率。
- **模型不通怎么办？** 基础交互仍由解释器处理；终端未知命令最多等待8秒，按需研判最多等待12秒后降级。界面按真实来源标识结果。
- **局限是什么？** 虚拟解释器不等于完整 Linux；未验证任意 shell 语法、长期负载或生产防御效果。

## 现场不要做的事

不要把 Agent 的思考等待误认为服务器卡死；不要说每条命令都由大模型生成；不要说模拟隔离真的封禁了主机；不要现场为了让 JIT 计数上涨而凭空指定一个地址。

若 Agent 拒绝连接，先明确课设所有权和仿真范围；仍拒绝就使用已验证可执行 SSH 的 Agent 或手工 SSH，不在台上反复改提示词。若探索已经拿到足够证据，停止探索、切到回放即可。
