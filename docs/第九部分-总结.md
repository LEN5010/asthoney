# 第九部分 工程项目开发总结

本文对应课程报告第九部分，按当前代码写。启动准备初稿（2026-09-15）只覆盖第三、四、五部分，其中测试记录仍是 14 项、入口仍写成纯仿真 SSH。下面这段用来替换那一版里已经过时的结论。

## 9.1 做成了什么

系统在一台机器上把诱捕、决策、图存储和态势面板串成闭环。

- 外层 2222 用真实 SSH 完成握手。主机密钥和登录私钥由蜜罐生成，登录用户是 `svc-backup`。认证通过后的每一行命令进入 LangGraph，不在宿主机执行。
- 主智能体按分析、规划、路由、终端仿真、输出护栏五步处理一条命令。规划员和护栏是确定性规则，终端演员先查会话世界，没有命中才考虑大模型。没配模型密钥时演示仍然成立。
- 跳板、数据库副本和对象存储桥各有一套目录。目录里列出来的文件都有固定正文。管道、`grep`、`head`、重定向和 `bash -c` 只改会话世界。
- 读凭证留在当前主机。只有 `ssh` 到内网地址才换主机，上一台新建的文件留在同一份快照里。内层地址不是第二个真实端口。
- Neo4j 保存预置迷宫、会话、意图、告警、决策轨迹和世界快照。未知地址才会即时合成节点。
- MCP 同时提供 REST 和 JSON-RPC。公开工具像内部助理，旧的危险工具名仍返回 403 并记 critical。
- 态势面板能看决策流水线、资产拓扑、会话回放、主机世界、ATT&CK 子集和可解释威胁分。公开回看世界时口令和私钥打码，管理令牌才能看全文。

## 9.2 和启动初稿的差别

启动初稿把入口写成 TCP/SSH 仿真，测试写成 `POST /simulate` 注入 `whoami`，单元测试记为 14 项通过。现在主路径是 `ssh -i var/ssh/lure_ed25519 -p 2222 svc-backup@127.0.0.1`，也可以在面板点注入演示序列。单元测试覆盖意图、规划、文件系统、真实 SSH 握手，以及一条从 SSH 到图快照的会话。安全冒烟脚本覆盖鉴权、超长输入、危险命令、MCP 陷阱和密钥权限。

隔离仍然只写模拟动作，不改真实网络。2323 仍是原始 TCP 横幅。进程重启后能恢复告警和隔离计数，活着的解释器状态不恢复，只保留最后一次世界快照。

## 9.3 还没收进运行时的边界

- 大模型是可选项。生成式指的是终端演员可以调用模型，规划员和护栏不调用模型。
- 内层横向是仿真登录记录加另一份文件系统，不是第二段 SSH 握手。
- 解释器没有覆盖完整 bash。不认识的命令仍走确定性拒绝或模型，不会落到宿主机。
- 面板本身没有登录页。敏感全文靠 `X-Admin-Token`，其余只读接口仍对实验机开放。

## 9.4 结论

课题按软件过程走完了需求、设计、实现和测试：诱捕入口、可复现的欺骗决策、图上的攻击轨迹、面向 Agent 的工具诱饵，以及能回放的态势界面。演示不依赖外网模型，危险命令和隔离都不碰真实系统。这是一套能在课堂里跑通、也能讲清边界的欺骗防御原型。
